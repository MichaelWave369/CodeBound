# Contributing to CodeBound

This project is for practical, peaceful, evidence-driven community resilience. PRs with tested instructions, references, accessible wording, diagrams, translations, and simple software examples are welcome.

1. Open an issue describing the problem and the people helped.
2. Add or update a guide in data/guides.js with a unique ID, clear materials, ordered steps, checks, cautions, and dependencies.
3. Cite primary sources and mark its review level honestly.
4. Run npm test and manually test offline behavior.
5. Include environment assumptions, field-test notes if any, and what may go wrong.

No weaponization, harmful chemicals, unauthorized radio operations, oppressive governance mechanisms, doxxing, dangerous medical advice, unqualified mains wiring, or instructions to contaminate resources.
